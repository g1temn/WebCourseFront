# WebCourseFront — план реалізації

Сайт дисципліни **«Web-технології та web-дизайн»** (ФІТ, НТУ «Дніпровська політехніка», спеціальність
F2 «Інженерія програмного забезпечення», 2 курс, 1 семестр): інформація про курс, **11 лабораторних робіт**
(кожна — окрема сторінка), **редактор коду** в окремому вікні та україномовні **матеріали**.

> **Джерело правди для вигляду — затверджений мок-ап** (полотно https://claude.ai/artifact/BWDpJeWbPg29hj2HewBiVX,
> SVG-експорт усіх 16 кадрів — у `design/figma-svg/`). Код відтворює мок-ап на трьох ширинах: 1440 / 768 / 390.

- **Стек:** React 19 + TypeScript + Vite, `react-router`, SCSS Modules, CodeMirror 6 (лише в редакторі).
- **Без бекенду.** Увесь статичний зміст і моки (FAQ, матеріали) лежать у **`src/static-content/`** і
  імпортуються напряму. Ніякого `src/api`, ніякого TanStack Query.
- **Мова:** лише українська, тільки офіційно-ділова лексика («лабораторна робота», «методичні вказівки»).
- **Не робимо зараз:** адмінку (`/admin`), авторизацію, тести, деплой.

## 3. Стилі — нічого не хардкодимо

Усі значення — змінні SCSS у `src/styles/`; компоненти беруть кольори й розміри лише звідти.

| Файл | Що містить |
|---|---|
| `_fonts.scss` | `@font-face` для власних woff2 (кирилиця + латиниця): Bitter, Rubik, Onest, JetBrains Mono |
| `_colors.scss` | Палітра мок-апу: `bg #FAF6F1`, `surface #FFF`, `sunken #F2E9DF`, `border #DCCCBA`, `text #1D1412`, `muted #574740`, **єдиний акцент** `primary #B3261E` (+ hover, soft, on-dark), `dark #2B1316`, кольори HTML/CSS/Figma лише для міток, код-підсвітка, оверлеї |
| `_typography.scss` | Сімейства (Bitter — H1–H2, Rubik — H3/кнопки/мітки/меню, Onest — текст, JetBrains Mono — код), розміри (display 54/40/32, h1 40/26, h2 28–36/22–24, h3 20, body 17/16, small 14, eyebrow 13 caps), висоти рядків + міксини `heading-1`… |
| `_spacing.scss` | Шкала відступів, ширина контейнера, gutter |
| `_radii.scss`, `_shadows.scss` | Радіуси 8 / 14 / 22 / pill, тіні card / pop |
| `_breakpoints.scss` | Телефон < 768, планшет 768–1199, ПК ≥ 1200 + міксини `tablet-up`, `desktop-up`, `phone-only` |
| `_flex.scss` | Міксини `flex-row`, `flex-col`, `flex-center`, `flex-between` |
| `_grid.scss` | Міксини `grid-cols($n)`, `auto-grid($min)` |
| `_mixins.scss` | `focus-ring`, `visually-hidden`, `bg-overlay($color, $image)`, `card` |
| `global.scss` | reset, базова типографіка, `code`, посилання, `:focus-visible` |

## 5. Сторінки лабораторних

**Кожна лаба — окрема сторінка**, складена з її змісту та спільних компонентів; набір і порядок секцій
у кожної свій. Дані (лістинги, рядки таблиць, кроки, питання) — у `static-content/labs/labN.ts`.
Сторінки лаб завантажуються ліниво (`React.lazy`) — код лаби вантажиться лише при переході на неї.

Обгортка `LabLayout` (за мок-апом): ліворуч сайдбар з усіма лабами за групами HTML / CSS / Figma
(на планшеті й телефоні — кнопка «Лабораторні роботи», що відкриває випадну панель), праворуч
«На цій сторінці» з підсвічуванням активної секції (на планшеті й телефоні — кнопка «Зміст: …»).

| Компонент | Вигляд у мок-апі |
|---|---|
| `LabHeader` | Хлібні крихти, мітка групи (`HTML · №2`), «2 години», H1, лід, «Відкрити редактор ↗» (HTML/CSS), «Методичні вказівки, PDF» |
| `Goals` | Картка «Мета роботи» з нумерованими кружечками |
| `LabSection` | «Розділ N» + H2 з якорем; реєструється в «На цій сторінці» |
| `RefTable` | Таблиця з заголовком і пошуком; на телефоні — картки; «Показати всі N …» |
| `CodeListing` | «Лістинг 2.1 · файл», «Копіювати», підсвічений код; знизу — **скріншот результату** (`Figure`) |
| `Figure` | Зображення + підпис «Рис. N», «Збільшити» (перегляд на весь екран) |
| `Callout` | `modern` «Сучасний погляд», `warning` «Зверніть увагу», `tip` «Порада», `info` |
| `Compare` | Картки поруч (наприклад, три види списків) |
| `ProcessFlow` | Пронумеровані етапи |
| `StepList` | «Хід роботи» з прогресом «Виконано X з N», чекбокси в `localStorage`, «Показати ще» |
| `StepGallery` | Кроки Figma-лаб: інструкція + скріншот |
| `ControlQuestions` | Нумерований список питань (без відповідей) |
| `LabFiles` | «Файли до роботи»: мініатюри, **«Копіювати посилання»** (повна адреса для редактора) + завантаження; лише для лаб з архівом |
| `PrevNext` | «← Попередня · HTML №1» / «Наступна · HTML №3 →» |

## 6. Редактор коду (`/editor`, окреме вікно)

- **Не прив'язаний до лаби.** Відкривається завжди в новому вікні/вкладці.
- **Проєкти:** випадний список «Проєкт» (створити / перейменувати / видалити), кожен проєкт — набір файлів
  з папками (`index.html`, `css/style.css`, `js/script.js`).
- **Панелі (ПК):** «Файли» (дерево, «+ файл», «+ папка», підказка про зображення) · код з вкладками
  відкритих файлів і «+ Файл» · «Результат» (`iframe`) з «Оновити» і згортальною «Консоллю».
- **Планшет:** перемикач «Код · Код і результат · Результат», дерево файлів ліворуч від коду.
- **Телефон:** вкладки «Файли · Код · Результат», меню `⋯` (.zip, скинути).
- **Код:** CodeMirror 6 (`@codemirror/lang-html`, `lang-css`, `lang-javascript`), кольори підсвітки — з токенів;
  завантажується ліниво лише на сторінці редактора.
- **Результат:** `iframe`. Редактор кладе файли проєкту в Cache API за адресами `/preview/<id>/<шлях>`, а невеликий
  service worker (`public/preview-sw.js`) віддає їх як звичайний сервер — тому працюють відносні шляхи
  (`css/style.css`, `js/script.js`), переходи між сторінками і `iframe` з `target`. Якщо service worker недоступний,
  CSS і JS вбудовуються в `srcdoc` поточної сторінки. `console.*` і помилки передаються в панель «Консоль» через `postMessage`.
- **Автозбереження** в `localStorage` (~400 мс після зміни), індикатор «Збережено в браузері».
  Ключі: `wc:editor:projects` (список), `wc:editor:project:<id>` (файли), `wc:editor:active`.
- **«Завантажити .zip»** — власний мінімальний ZIP-запис (без пакетів). **«Скинути»** — повернути стартові файли (з підтвердженням).
- **Зображення** — лише за повною адресою; посилання копіюються на сторінці лаби («Файли до роботи»).

## 7. Моки (`static-content`)

```ts
type TechGroup = "html" | "css" | "figma";
interface FaqItem { id: string; question: string; answer: string; labSlug?: string } // є labSlug → мітка «HTML · №5»
interface Resource {
  id: string; kind: "course" | "docs" | "article"; tech: TechGroup;
  title: string; author: string; url: string; description?: string;
  labSlugs: string[]; lang?: "uk" | "en"; featured?: boolean;
}
```

Форма «Задати питання»: ім'я*, email, лабораторна (необов'язково), питання*. Поки нікуди не надсилає:
перевіряє поля, показує «Дякуємо! Відповідь з'явиться в розділі FAQ», очищає форму.
